# 개인 데이터 자동 동기화와 원어 해설 작업공간 설계

## 요약

Rust/Tauri 데스크톱 앱에 두 가지 연결된 개선을 추가한다.

1. 사용자가 선택한 Synology Drive 폴더를 통해 노트와 UI 상태를 자동으로
   동기화한다.
2. 주 성경의 원어 단어를 직접 클릭해 오른쪽 전체 높이의 원어 해설을 열고,
   용례를 왼쪽 아래의 임시 성경 패널에서 탐색한다.

앱은 실행 중인 SQLite 데이터베이스를 클라우드 폴더에서 직접 열지 않는다.
각 컴퓨터는 로컬 `user.db`를 사용하고, 검증된 개인 데이터 스냅샷만 동기화
폴더에 원자적으로 기록한다. 이렇게 하면 사용자는 클라우드 데이터베이스와
유사한 자동 동기화 경험을 얻으면서 SQLite 파일 동기화 충돌과 손상을 피할 수
있다.

## 목표

- 책·장·절 Markdown 노트와 UI/작업공간 상태를 여러 Linux 컴퓨터에서 이어서
  사용한다.
- 한 컴퓨터에서 앱을 닫은 뒤 다른 컴퓨터에서 여는 일반적인 사용 흐름을 자동화한다.
- Synology Drive가 일시적으로 사용할 수 없어도 로컬 읽기와 편집을 계속한다.
- 충돌이나 실패가 개인 데이터를 조용히 덮어쓰거나 삭제하지 않게 한다.
- 원어를 항상 원문 어순으로 주 성경에 표시하고 각 단어를 직접 선택할 수 있게 한다.
- 절 전체 분석 단계를 제거하고 선택한 단어의 해설과 용례에 화면을 집중한다.
- 용례를 살피는 동안 주 성경의 책·장·절과 스크롤 위치를 보존한다.

## 범위 밖

- Synology API, 계정 로그인 또는 네트워크 프로토콜을 앱에 내장하는 기능.
- 실행 중인 `user.db`를 Synology Drive 폴더에서 직접 여는 기능.
- 여러 컴퓨터가 같은 노트를 동시에 편집하는 실시간 협업.
- 동기화 파일의 종단 간 암호화. 선택한 Synology 폴더의 접근 권한을 신뢰한다.
- 검증되지 않은 영어 번역 어순을 원문에 적용하는 기능.
- 용례 미리보기에서 노트, 검색 또는 여러 임시 성경 패널을 여는 기능.

## 현재 상태와 결정 근거

개인 데이터는 Linux에서 앱 데이터 디렉터리의 `user.db`에 저장된다. 이 DB에는
하나의 설정/작업공간 JSON과 책·장·절 노트가 들어간다. 번역 본문과 원어 자료는
읽기 전용 번들 `bible.db`에 있으므로 동기화 대상이 아니다. 현재 ZIP 내보내기와
가져오기는 노트만 포함하고 UI 상태는 포함하지 않는다.

현재 생성된 원어 데이터의 `translationOrder`를 전체 444,065개 토큰에서 조사한
결과, 모든 값이 원문 토큰 순서와 같았다. `alignment_status`도 검증된 영어 정렬을
제공하지 않는다. 따라서 `Translation order`를 별도 판본이나 정렬 모드로 노출하는
것은 실제 데이터와 맞지 않는다. UI에서는 원문 어순만 제공한다. 나중에 재배포가
가능한 검증된 정렬 데이터가 생기면 토큰 순서 필드가 아니라 명시적인 다대다 정렬
그룹으로 별도 기능을 설계한다.

## 개인 데이터 동기화 구조

### 로컬 권위 저장소

각 컴퓨터는 기존 앱 데이터 폴더의 `user.db`를 실행 중 권위 저장소로 사용한다.
SQLite 연결, 자동 저장, 앱 업데이트 시 스키마 마이그레이션은 모두 로컬 DB에서만
수행한다. 사용자가 동기화를 해제하거나 Synology Drive가 오프라인이어도 로컬
데이터는 그대로 남는다.

동기화 폴더의 절대 경로와 로컬 장치 ID는 장치별 설정으로 보관하고 다른 컴퓨터로
동기화하지 않는다. 각 컴퓨터에서 실제로 동기화되는 동일 Synology 폴더를 한 번씩
선택한다.

### 동기화 스냅샷

선택한 폴더 아래에 앱 전용 디렉터리와 버전이 지정된 개인 데이터 스냅샷을 둔다.
스냅샷은 다음 논리 데이터를 포함한다.

- 형식 버전과 스냅샷 ID;
- 생성 장치 ID와 생성 시각;
- 이전에 반영한 기반 스냅샷 ID;
- UI/작업공간 상태와 수정 시각;
- 모든 책·장·절 노트의 reference key, Markdown, 수정 시각;
- 다른 장치에 삭제를 전달하기 위한 note tombstone;
- 무결성 검사용 체크섬.

개인 데이터 형식은 앱 DB의 내부 테이블 배치와 분리한다. 앱 버전이 달라도 지원하는
동기화 형식을 검증하고 마이그레이션할 수 있어야 한다. 기존 사람이 읽을 수 있는
노트 ZIP 백업은 별도 수동 기능으로 유지한다.

### 원자적 기록

새 스냅샷은 선택한 동기화 디렉터리 안의 고유 임시 파일에 완전히 기록한다. 파일을
다시 열어 버전, 체크섬과 필수 필드를 검증한 후에만 최종 파일명으로 rename한다.
기존의 유효한 스냅샷은 새 스냅샷 교체가 성공하기 전까지 유지한다. 앱이나 Synology
Drive가 기록 도중 중단되어도 다음 실행에서 마지막 유효 스냅샷을 사용할 수 있어야
한다.

### 저장과 불러오기 시점

- 앱 시작: UI 상태를 불러오기 전에 동기화 폴더의 최신 유효 스냅샷을 검사하고
  로컬 데이터와 병합한다.
- 노트 저장·삭제 또는 UI 상태 저장: 로컬 DB에 먼저 커밋한 뒤 짧은 debounce를
  거쳐 스냅샷을 갱신한다.
- 창 재활성화: 로컬의 미저장 변경을 먼저 끝낸 뒤 새로운 원격 스냅샷을 검사한다.
- 수동 `지금 동기화`: 같은 pull-merge-push 파이프라인을 즉시 실행한다.
- 앱 종료: 진행 중인 노트 저장과 스냅샷 기록을 제한된 시간 안에 최종 시도한다.

Synology Drive가 파일을 늦게 내려받는 경우 원격 파일 부재를 삭제 신호로 해석하지
않는다. 로컬 작업은 계속하고 상태를 `폴더를 기다리는 중`으로 표시한 뒤 재활성화나
수동 동기화 때 다시 확인한다.

### 첫 연결과 병합

동기화 폴더에 스냅샷이 없으면 현재 로컬 데이터로 첫 스냅샷을 만든다. 기존
스냅샷이 있으면 로컬 데이터를 먼저 보존한 상태로 병합한다. 노트는 reference key와
수정 이력으로 비교하고, UI 상태는 가장 최근의 유효한 값을 사용한다.

정상적인 순차 사용에서는 다른 장치가 만든 최신 스냅샷을 적용하고 그 스냅샷을
새 기반으로 기록한다. 삭제는 tombstone이 해당 노트보다 새로울 때만 적용한다.

### 충돌

같은 기반 이후 동일한 reference key가 양쪽에서 다르게 수정되었거나 한쪽에서
삭제되고 다른 쪽에서 수정되면 자동 덮어쓰지 않는다. 충돌 레코드는 양쪽 Markdown,
수정 시각과 장치 정보를 모두 보존한다. 앱은 충돌 목록을 보여 주고 사용자가 다음
중 하나를 선택하게 한다.

- 로컬 내용 유지;
- 다른 컴퓨터의 내용 사용;
- 두 내용을 구분선과 출처 정보와 함께 합치기.

결정을 로컬 DB에 커밋한 뒤 새 스냅샷을 기록한다. UI/작업공간 상태는 글 내용과
달리 충돌 대화상자를 만들지 않고 가장 최근 값을 사용한다. 동기화 설정 경로와 장치
ID는 항상 로컬 값을 유지한다.

### 동기화 설정 UI

설정에 `개인 데이터 동기화 폴더` 항목을 추가한다. 사용자는 폴더 선택, 지금
동기화, 폴더 변경과 동기화 해제를 할 수 있다. 해제는 로컬 개인 데이터를 삭제하지
않는다.

상태 표시는 다음을 구분한다.

- 동기화됨;
- 저장 중;
- 다른 컴퓨터의 변경 반영됨;
- Synology 폴더를 기다리는 중;
- 동기화 실패;
- 충돌 확인 필요.

실패 메시지는 마지막 유효한 로컬/원격 데이터가 보존되었는지 명시하고 재시도
동작을 제공한다.

## 원어 표시와 해설 작업공간

### 주 성경의 원어

원어가 활성화된 주 성경은 각 절 아래에 원문 어순으로 토큰을 표시한다. Hebrew와
Aramaic은 RTL, Greek은 LTR을 사용한다. 각 토큰은 키보드 접근이 가능한 버튼이며
원문, 음역과 짧은 문맥상 의미를 표시한다. 선택된 토큰은 주 성경에서도 지속적으로
강조한다.

`Translation order / Original order` 전환, 절 전체 토큰을 다시 나열하는 기존
`VERSE ANALYSIS` 상단 영역과 원어 블록 전체를 클릭해 절 분석을 여는 동작은
제거한다. 원어 단어 선택은 곧바로 단어 해설을 연다.

### 오른쪽 전체 높이 단어 해설

단어를 클릭하면 현재 오른쪽 보조 작업공간의 패널 구성, 크기와 활성 패널을 메모리에
보관한다. 기존 보조 성경과 노트는 숨기고 단어 해설 패널이 오른쪽 전체 높이를
차지한다. 다른 단어를 클릭하면 패널을 다시 만들지 않고 내용을 교체한다.

해설 내용은 하나의 자연스러운 세로 스크롤 안에 다음 순서로 배치한다.

1. 큰 원문 표기, 음역, lemma와 Strong 번호;
2. 문맥상 의미와 형태론 설명;
3. 짧은 사전 뜻과 상세 정의;
4. 데이터 출처와 라이선스;
5. 현재 권 용례와 개수;
6. 동일 형태론 필터;
7. 성경 전체 용례 전환;
8. 50건 단위 추가 로딩.

넓어진 패널에서는 필드 label/value의 대비와 본문 행간을 높이고, 원어·lemma와
용례 참조를 명확한 시각 계층으로 구분한다. 중첩된 고정 높이 스크롤 영역은 만들지
않는다.

### 왼쪽 아래 임시 성경 패널

용례 결과를 클릭해도 기존 주 성경을 이동하지 않는다. 대신 왼쪽 주 영역을 세로로
나누고 아래에 하나의 임시 성경 패널을 연다.

```text
┌──────────── 왼쪽 주 영역 ────────────┬──── 오른쪽 ────┐
│ 기존 주 성경 — 위치와 스크롤 유지     │ 원어 해설       │
├──────────────────────────────────────┤ 사전·형태론·용례 │
│ 용례 탐색용 임시 성경 패널            │                 │
└──────────────────────────────────────┴─────────────────┘
```

임시 패널은 처음 열릴 때 주 성경의 번역 구성을 복사하지만 이후 독립적으로 번역을
추가하거나 제거할 수 있다. 클릭한 절을 표시하고 이전 절·다음 절 이동을 제공한다.
장 경계를 넘으면 이전 장 마지막 절 또는 다음 장 첫 절로 이동한다. 다른 용례를
클릭하면 새 패널을 추가하지 않고 같은 임시 패널의 위치만 변경한다. 사용자는 주
성경과 임시 패널의 높이 경계를 조절할 수 있다.

임시 패널에는 이 탐색에 필요한 번역 선택, 현재 책·장·절 표시와 앞뒤 절 이동만
둔다. 검색, 노트와 추가 임시 패널 생성은 제공하지 않는다.

### 닫기와 복원

단어 해설을 닫거나 `Ctrl+W`로 종료하면 임시 용례 패널도 함께 닫는다. 왼쪽 주
성경은 전체 높이를 되찾고, 단어 해설을 열기 전에 있던 오른쪽 보조 성경·노트 구성과
크기를 그대로 복원한다. 주 성경의 책·장·절, 선택과 스크롤 위치는 해설 세션 전체에서
바뀌지 않는다.

작은 화면에서는 동시에 세 영역을 압축하지 않는다. 기존 main/auxiliary 전환 모델을
따르고 임시 용례 성경은 해설 세션 안의 별도 탭으로 제공한다.

## 오류 처리

- 단어 사전 조회가 실패하면 선택과 작업공간은 유지하고 패널 안에서 재시도한다.
- 용례 조회가 실패하면 이미 로드한 사전 정보는 유지한다.
- 오래된 비동기 단어·용례 응답은 새 선택 결과를 덮어쓰지 않는다.
- 임시 패널의 번역에 해당 절이 없으면 다른 선택 번역은 유지하고 누락 상태를
  표시한다.
- 동기화 파일이 없거나 부분 파일이면 로컬 데이터를 삭제하지 않는다.
- 지원하지 않는 미래 동기화 버전은 읽지 않고 사용자에게 앱 업데이트를 안내한다.
- 체크섬 불일치나 손상된 스냅샷은 격리하고 마지막 유효 스냅샷을 유지한다.
- 폴더 권한과 디스크 공간 오류는 로컬 저장 성공 여부와 클라우드 저장 실패를
  구분해 표시한다.

## 검증 전략

### 개인 데이터 동기화

- 새 로컬 데이터에서 첫 스냅샷 생성;
- 원격 데이터가 있는 새 컴퓨터의 최초 가져오기;
- A에서 저장·종료한 뒤 B에서 시작하는 순차 장치 시나리오;
- 노트 저장, 삭제 tombstone과 UI 상태의 왕복;
- 동일 노트 수정과 삭제/수정 충돌에서 양쪽 내용 보존;
- 임시 기록 중단 후 이전 스냅샷 유지;
- 체크섬 불일치, 미래 버전, 읽기 전용 폴더와 디스크 오류;
- Synology 폴더 부재 중 로컬 편집 후 재연결;
- 동기화 해제 후 로컬 데이터 보존;
- 기존 `user.db`와 노트 ZIP 기능의 회귀 테스트.

### 원어 작업공간

- 원문 어순과 Hebrew/Aramaic RTL, Greek LTR;
- 마우스와 키보드로 개별 단어 선택;
- translation-order 컨트롤과 절 전체 분석 영역 제거;
- 단어 전환 시 stale 응답 차단과 선택 강조;
- 오른쪽 전체 높이 해설과 기존 보조 작업공간 복원;
- 용례 클릭 시 주 성경 reference와 스크롤 불변;
- 임시 패널의 번역 상속 후 독립 변경;
- 앞뒤 절 및 장 경계 이동;
- 여러 용례 클릭 시 단일 임시 패널 재사용;
- 높이 조절, `Ctrl+W`, 작은 화면 탭 동작;
- 실제 AppImage에서 오프라인 사전·용례·노트·동기화 스냅샷 스모크 테스트.

## 배포와 마이그레이션

기존 사용자의 `user.db`를 제자리에서 마이그레이션하고 동기화를 기본으로 강제하지
않는다. 사용자가 폴더를 선택할 때만 첫 스냅샷을 만든다. 기존 노트와 UI 상태는
그대로 유지되며 수동 ZIP 백업도 계속 사용할 수 있다.

원어 UI 상태를 읽을 때 이전 `analysisMode`와 열린 절 분석 상태는 폐기하고, 성경
패널과 노트 작업공간 상태만 보존한다. 번들 `bible.db`는 개인 데이터 동기화 대상에
포함하지 않는다.
